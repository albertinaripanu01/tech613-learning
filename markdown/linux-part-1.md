| Command | Purpose |
| --- | --- |
| `pwd` | Show current folder |
| `ls` | List files and folders |
| `ls -la` | List all files, including hidden files, with details |
| `cd folder` | Move into a folder |
| `cd ..` | Move to the parent folder |
| `cd ~` | Move to the home folder |
| `mkdir folder` | Create a folder |
| `touch file.txt` | Create an empty file |
| `cat file.txt` | Display file contents |
| `file file_name` | shows information about the file specified |
| `nano file.txt` | Edit a file in Terminal |
| `cp file1 file2` | Copy file1 with name file 2 |
| `mv old new` | Rename or move a file |
| `rm file.txt` | Delete a file |
| `rm -r folder` | Delete a folder and its contents **DANGER** |
| `clear` | Clear the terminal |
| `history` | Show previous commands so you can find a command used earlier |
| `man "command"` | Open a command manual for the specified command (eg `man ls` will open a manual for the ls command) |
| `exit` | End the SSH session |
| `--help` | Shows helpful options eg `rm --help` shows options for rm command |
| `whoami` | Show the current username |
| `ls -a` | List all files and folders, including hidden ones |
| `ls -al` | List all files, including hidden files, with details (same as `ls -la`) |
| `uname` | Show the kernel name |
| `uname --help` | Show help and options for `uname` |
| `cat /etc/shells` | Display the list of valid login shells in `/etc/shells` |
| `ps -p $$` | Show process information for the current shell (`$$` is its process ID) |
| `mv file folder/` | Move a file into a folder; replace `file` and `folder/` with your paths |
| `tail -2 chicken-joke.txt` | Display the last two lines of the file |
| `head -2 chicken-joke.txt` | Display the first two lines of the file |
